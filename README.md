# Credit-Risk-Prediction-Loan-Default-Analytics
An end-to-end machine learning system using Python, SQL, XGBoost, Power BI, and Streamlit to predict loan default risk and analyze credit risk.

💳 **Credit Risk Prediction & Loan Default Analytics System**

📌 **Project Overview**

An end-to-end machine learning project designed to predict loan default risk using applicant financial, loan, and credit characteristics. The system combines predictive modeling, Power BI visualization, and an interactive Streamlit application to support data-driven credit risk assessment.

🎯 **Project Objectives**

Predict the probability of loan default.

Identify high-risk loan applicants.

Compare machine learning classification models.

Analyze loan default trends and risk segments.

Provide applicant-level risk predictions.

🛠️ **Tools & Technologies**

Python – Data analysis and model development.

SQL – Data querying and analysis.

Scikit-learn – Machine learning and preprocessing.

XGBoost – Predictive modeling.

Power BI – Interactive risk analytics dashboard.

Streamlit – Interactive prediction application.

🤖 **Machine Learning Models**

Logistic Regression

Random Forest

XGBoost

Models were evaluated using Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrix.

📊 **Key Features**

Data cleaning and exploratory data analysis.

Feature engineering and categorical encoding.

Loan default probability prediction.

Low, Medium, and High risk classification.

Interactive Power BI dashboard.

Streamlit-based applicant risk prediction.

💡 **Project Outcome**

Built an integrated analytics solution that combines machine learning and business intelligence to assess credit risk, visualize portfolio trends, and generate applicant-level predictions.
